Yes, with limits. The human-transcribed pages only feed the CER benchmark. Everything else already runs without them.

What works with zero human input

- The gate itself. It scores every candidate from the ink and the writer's own script, and writes the verdicts, the crops, and the "Flagged for Human Review" list. That run is in progress on script 0002 now.
- Ablations by mode. Run the same script with arbitration.mode set to evidence, legacy, and off, then diff the error lists. This shows what changed, but not which version is right.
- Downstream check against the marks you already have. Run Stage 4 on the evidence and legacy outputs and compare the mean absolute error against gt.txt for the two scripts with teacher marks. Stage 0b also harvests margin marks from the other scripts, so more ground-truth marks exist for a quick eyeball check.

What you lose without any labels

- The fusion weights stay at provisional defaults, so verdicts are uncalibrated and the thesis cannot report gate precision or recall.
- No transcription accuracy number, so you cannot say whether Stage 2 helps or hurts.

Recommended steps, cheapest first

1. Let the current run finish, then run the remaining Englishhe arbitration tables in each extraction summary.
2. Label crops, not pages. Run the labelling script, open the contact sheets, and mark each crop G, A, or U. About 100 crops takes roughly 30 to 45
   minutes and is a glance-level judgment, not transcription.e evaluate script. This is the step that turns the gate into a
   measurable result.
3. Run Stage 4 on both modes and compare against gt.txt. That is your zero-effort downstream validation.
4. Defer page transcription, or shrink it. Five corrected pages give a rough CER. Correcting a machine draft runs about 5 minutes per page.

So the order is: crops before pages. The crop labels matter more for the thesis claim, and they are much cheaper.
