# 9_17_26 — Multi-Class Extraction + Evaluation Pipeline

Builds on `8_25_26`. The pipeline now handles several question papers ("exam
sets") and grades **every** question on a paper, not only the writing section.

| Exam set | Class | Scripts | Questions | Graded rows | Grader | k |
|---|---|---|---|---|---|---|
| `SE_11_Q1` | XI | 20 | 6 (writing) | 120 | gemini + gemma | 3 |
| `SE_07_Q1` | VII | 35 | 13 (full paper) | 455 | gemma | 1 |
| `SE_06_Q1` | VI | 22 | 13 (full paper) | 286 | gemma | 1 |

## What changed since 8_25_26
- **Exam sets.** A script's set is its id minus the serial
  (`SE_07_Q1_0003` → `SE_07_Q1`). Each set has its own task stems, extraction
  prompt, rubric, target questions and output paths in `config.yaml`. Every stage
  takes `--set`. See `docs/exam_sets.md`.
- **Full-paper grading.** Class VI/VII reading questions (MCQ, gap-fill,
  vocabulary, table, true/false, sentence transformation / preposition use,
  rearrangement, poem questions) are item-scored against answer keys carried in
  `data/Question/task_stems_<set>.csv` (generated by
  `scripts/gen_task_stems_<set>.py`). Writing questions are graded holistically.
- **Rubrics / prompts:** `prompts/rubric_c7_v1.txt`, `prompts/rubric_c6_v1.txt`,
  `prompts/extraction_prompt_c7_v1.md`, `prompts/extraction_prompt_c6_v1.md`.
  Class XI files are unchanged.
- **Rate limiting.** Client-side token/request pacing for the AI Studio free
  tier, plus a pool of API keys worked in rotation (`api_key_envs`).
- Sub-score ceilings are keyed by (question type, max mark); structural caps are
  fractions of max mark.

## Layout
- `data/transcripts/` — verbatim per-script transcripts (all sets)
- `data/extraction_<set>.csv` — answer-grain extraction (Class XI: `extraction.csv`)
- `output/SE_07_Q1/`, `output/SE_06_Q1/` — `evaluation.csv`, `evaluation_avg.csv`,
  `evaluation_runs.csv`, `evaluations/` (one JSON per task × model × run)
- `output/` (top level) — Class XI results, as in 8_25_26
- `logs/` — validation and evaluation reports per set

## Run
```
python -m venv .venv && .venv/Scripts/pip install -r requirements.txt
bash scripts/run_set.sh SE_06_Q1
```
or stage by stage: `01_convert.py`, `02_extract.py`, `03_validate.py`,
`04_build_csv.py`, then `scripts/eval/01_evaluate.py`, `02_emit_csv.py`,
`04_emit_avg.py`, `03_validate.py` — each with `--set <SET>`.

API keys are read from a local `.env` (never committed). Raw PDFs and
`data/images/` are not tracked.

## Known limitation
Class VI Q10 (poem questions) is graded against an indicative key: the poem
texts are not printed on the question paper.
