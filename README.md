# Undergraduate Thesis Project

This is the first documentation for the project.

## Project Structure

The project folder includes the following directories:

- script/ - Scripts used for data processing, analysis, or automation
- code/ - Source code for the main implementation
- result/ - Output files, generated results, and experiment artifacts
- presentation/ - Presentation materials and slides
- paper/ - Thesis paper and related documentation

## Additional Folders

The following folders are also included to support development and organization:

- data/ - Raw or processed datasets
- docs/ - Additional project documentation
- tests/ - Test cases and validation scripts
